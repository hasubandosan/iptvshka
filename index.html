Мои каналы · не сохранено

Плейлисты, в которых скрипт ищет ваши каналы. Чем выше в списке, тем приоритетнее: при одинаковых каналах побеждает верхний источник. Хранятся в config.json.

Источники ещё не загружены. Нажмите «Загрузить с GitHub» (кнопка на вкладке «Каналы»), чтобы случайно не затереть остальные настройки.

Подключение к GitHub

Нужно, чтобы загружать и сохранять channels.json прямо в репозиторий. После сохранения GitHub Actions сам пересоберёт плейлист.

Создайте fine-grained токен (GitHub → Settings → Developer settings → Personal access tokens) только для этого репозитория с правом Contents: Read and write. Токен хранится только в вашем браузере.
